오픈마켓 주간 보고쿠팡 · 토스 · 네이버 (10/26 ~ 11/1)

쿠팡

쿠팡 주간 보고 · 체질 개선 완료와 매출 확대 단계로 전환

10/26 ~ 11/1 · 지난주(10/19~10/25) vs 이번 주(10/26~11/1) 주간 비교

결론 →
이번 주는 순이익률을 끌어올리는 체질 개선에 집중했고, 목표를 달성했습니다. 순이익률은 5.29%에서 7.60%로 한 주 만에 2.31%p 올라 주간 기준 최고 기록을 세웠고, 11/1에는 하루 순이익률이 처음으로 10%를 넘었습니다. 광고비를 19.5% 줄이면서 매출은 11.0% 줄었지만, 순이익은 382.2만 원에서 488.7만 원(▲27.9%)으로 늘었습니다. 하루 평균 순이익도 54.6만 원에서 69.8만 원으로 올랐습니다.
이유 →
  • 광고비 다이어트: 버티는 선까지 예산 정리 → 효율이 무너지는 구간의 예산을 걷어냈습니다. 떡갈비 신규고객광고를 35만 원에서 25만 원으로 줄여도 하루 신규 고객은 40~48명으로 유지됐고, 1명당 비용은 7,255원에서 5,216~6,274원으로 낮아졌습니다. 떡갈비 일반 광고(25만 → 20만 원), 고들빼기(13만 → 10만 원), 깻잎순(13만 → 10만 원)도 예산을 줄이자 ROAS가 회복했습니다. 순이익률 상승분 2.31%p 중 1.53%p가 광고비 비율 감소에서 나왔습니다.
  • 상품 구조 개선: 가격·썸네일·리뉴얼 → 동치미를 천수무 동치미로 리뉴얼하고 3kg 옵션을 추가했으며, 5kg 가격을 14,900원에서 13,900원으로 낮춰 주말 하루 판매 51.7개, 전환율 10.25%를 만들었습니다. 쌈배추·총각김치 썸네일 교체로 클릭률이 약 2배 올랐고, 파김치는 웰빙촌 상품으로 리뉴얼한 뒤 주말 3일 판매가 18개로 늘었습니다. 광고 전 마진율은 21.2%에서 22.0%로 올라, 순이익률을 0.77%p 끌어올렸습니다.
다음 과제 →
매출 볼륨을 키우면서 순이익률 지키기입니다. 떡갈비 일반 광고를 15만 원으로 줄였을 때 판매가 126개에서 100개로, 하루 순이익이 약 37만 원에서 25만 원으로 함께 빠지면서, 광고비를 줄이는 방식은 한계에 도달했다는 것을 확인했습니다. 11/2부터 손익분기보다 ROAS 여유가 큰 상품에 광고비를 단계적으로 늘리는 실험을 시작했습니다(떡갈비 일반 25만 원, 고들빼기 20만 원, 겉절이 목표 ROAS 900%, 생굴김치·총각김치 3만 원). 앞으로는 이번 주에 끌어올린 순이익률을 지키면서 매출을 함께 끌어올리는 작업을 하겠습니다.
지난주 (10/19~25)이번 주 (10/26~11/1)개선하락

금액 단위: 만 원(주간 합계). 광고비는 VAT 포함, 매출 ROAS는 매출 ÷ 광고비입니다. 순이익은 추세정리 시트의 추정 순이익 기준입니다. 세부 근거는 ② 상세 보고 탭에 있습니다.

1. 전략 방향

"상품마다 광고 효율이 최적화되는 값을 찾는다."

  • 방향 → 이번 주는 상품마다 광고 효율을 결정하는 요소들을 하나씩 바꿔 보면서, 순이익이 가장 커지는 최적의 값을 찾는 과정이었습니다.
  • 바꿔 본 요소
    • 일예산 → 떡갈비 일반 광고를 25만 원 → 20만 원 → 15만 원 → 20만 원으로 조정해, 하루 순이익이 가장 큰 예산(일반 20만 원 + 신규 25만 원, 약 37만 원)을 찾았습니다. 쌈배추·생굴김치·열무얼갈이도 예산을 늘렸다가 효율이 무너지면 한 단계 되돌려 버티는 선을 확인했습니다.
    • 목표 ROAS → 떡갈비 일반 광고를 800%에서 1,000%로 올려 봤지만, 예산이 꽉 찬 캠페인에서는 광고비와 비검색 비중이 그대로였습니다. 이런 캠페인의 실제 조절 수단은 예산이라는 것을 확인했습니다.
    • 썸네일 → 클릭률이 낮은 쌈배추·총각김치·포기김치·파김치의 썸네일을 바꿨습니다. 총각김치는 검색 클릭률이 약 2배, 포기김치는 1.70%에서 2.26%로 올랐습니다.
    • 판매가 → 전환율이 떨어진 동치미 5kg(14,900원 → 13,900원)과, 다른 용량보다 전환율이 낮은 포기김치 10kg(59,900원 → 57,900원)의 가격을 조정했습니다.
    • 상품 자체 → 효율이 나오지 않는 파김치는 웰빙촌 상품으로 리뉴얼했고, 동치미는 천수무 동치미로 리뉴얼하며 3kg 옵션을 추가했습니다.
  • 원칙 → 한 번에 하나씩, 한 단계씩 바꿔서 무엇이 효과를 냈는지 확인했습니다. 결과가 나쁘면 바로 되돌렸습니다.
  • 결과 → 순이익률이 5.29%에서 7.60%로 올라 주간 기준 최고 기록을 세웠고, 순이익은 382.2만 원에서 488.7만 원(▲27.9%)으로 늘었습니다.
  • 다음 단계 → 광고비를 줄이는 방향의 최적화는 떡갈비 15만 원 테스트에서 한계를 확인했습니다. 이제는 같은 방식으로 순이익률을 지키면서 매출을 함께 끌어올리는 값을 찾아갑니다.

2. 이번 주 성과

지난주(10/19~10/25)와 이번 주(10/26~11/1)를 주간 합계로 비교했습니다. (추세정리 시트 기준)

  • 매출 → 7,221.6만 원 → 6,429.3만 원 (▼11.0%)
  • 순이익 → 382.2만 원 → 488.7만 원 (▲27.9%)
  • 하루 평균 순이익 → 54.6만 원 → 69.8만 원
  • 순이익률 → 5.29% → 7.60% (▲2.31%p)
  • 광고비 (VAT 포함) → 1,147.3만 원 → 923.5만 원 (▼19.5%)
  • 매출 대비 광고비 → 15.9% → 14.4%
  • 매출 ROAS → 629% → 696%

흐름 → 하루 매출은 772.0만~1,092.5만 원으로 지난주보다 낮았지만, 하루 순이익은 51.8만~107.3만 원으로 매일 50만 원 이상을 지켰습니다(지난주 28.7만~87.4만 원). 10/29~10/31은 하루 매출 772만~839만 원으로 10월 중 가장 낮은 구간이었는데도 순이익률은 6.7~7.7%를 유지했습니다. 11/1에는 매출 1,060.6만 원, 순이익 107.3만 원, 순이익률 10.12%로 이번 주 최고의 날을 기록했습니다.

순이익률이 오른 이유 분해
광고 효율 개선 → 매출 대비 광고비가 1.53%p 낮아져, 순이익률을 +1.53%p 끌어올렸습니다.
마진 구조 개선 → 광고 전 마진율이 21.2%에서 22.0%로 올라, 순이익률을 +0.77%p 끌어올렸습니다.
상승분의 약 3분의 2는 광고비 다이어트, 3분의 1은 가격·상품 구성 개선에서 나왔습니다.

3. 실행한 액션과 결과

① 떡갈비: 최적 예산 조합 찾기

  • 실행
    • 일반 → 일예산 25만 원 → 20만 원(10/26), 목표 ROAS 800% → 1,000%(10/28), 20만 원 → 15만 원(10/29), 20만 원·목표 ROAS 800%로 복귀(10/30)
    • 신규고객광고 → 25만 원 유지
  • 20만 원 → 실제 광고비가 하루 약 30만 원에서 24만 원으로 줄었고, ROAS는 276%에서 365%로 회복했습니다.
  • 목표 ROAS 1,000% → 광고비 24.1만 원, 비검색 비중 94%로 그대로였습니다. 목표 ROAS로는 비검색을 줄일 수 없다는 것을 다시 확인했습니다.
  • 15만 원 → 광고비는 6만 원 줄었지만, 떡갈비 판매가 126개에서 100개로, 방문자가 600명 줄었습니다. 떡갈비 하루 순이익은 약 37만 원에서 25만 원으로 감소했습니다.
  • 배운 점 → 일반 광고의 비검색 영역(광고비의 93%)은 광고 ROAS가 손익분기(325%)보다 낮지만, 떡갈비를 알려서 방문자를 만드는 역할을 합니다. 떡갈비는 캠페인별 ROAS가 아니라 두 캠페인을 묶은 하루 순이익으로 판단합니다.
  • 결과 → 최적 조합은 일반 20만 원 + 신규 25만 원(하루 순이익 약 37만 원)입니다. 복귀 후 주말에 하루 120개를 판매해 하루 순이익 약 34.7만 원을 지켰습니다.
  • 신규고객광고 → 1명당 비용이 5,216~8,296원 사이였고, 주말 ROAS는 524% → 472% → 356%로 하락 중입니다.

② 동치미: 리뉴얼과 가격 조정

  • 실행 → 천수무 동치미로 상품명 변경, 3kg 옵션 추가, 일예산 20만 원 → 25만 원(10/26) / 5kg 판매가 14,900원 → 13,900원(10/29)
  • 리뉴얼 첫날 (10/26) → 매출 168.5만 원(주말 하루 123만 원 대비 ▲37%), ROAS 584%, 3kg 첫날 8건
  • 하락 (10/27~28) → ROAS 584% → 446% → 365%, 판매 101건 → 53건 → 44건
    • 진단 → 예산은 절반만 쓰여 예산 문제가 아니었습니다. 검색 클릭률이 4.49%에서 2.28%로, 전환율이 8.12%에서 6.08%로 떨어졌습니다. 다른 상품은 회복 중이어서 손님에게 보이는 가격을 가장 유력한 원인으로 판단했습니다.
  • 가격 인하 후 (주말) → 5kg 하루 51.7개 판매로 순이익 유지선(52개)과 거의 같습니다. 전환율은 10.25%로 회복했고, ROAS는 약 523%입니다.
  • 남은 과제 → 13,900원 기준 손익분기는 약 496%라 이익이 얇습니다(하루 약 3.6만 원).

③ 버티는 선 찾기: 늘렸다가 되돌린 실험

  • 쌈배추 → 2만 원 → 5만 원(10/27) → 2만 원(10/30)
    • 새 썸네일 효과로 ROAS 1,066%가 나와 5만 원으로 늘렸지만, 판매는 하루 10~13개로 같았고 ROAS는 196%까지 떨어졌습니다. 2만 원 복귀 후 주말 ROAS는 528% → 649% → 755%입니다.
  • 생굴김치 → 1만 원 → 3만 원(10/28) → 2만 원(10/29)
    • 3만 원 첫날 ROAS 330%로 무너졌고, 2만 원에서 605%로 회복했습니다. 주말 3일 이익은 +17.9만 원, 1kg 전환율은 11.03%입니다.
  • 열무얼갈이 → 1만 원 → 3만 원(10/28) → 2만 원(10/30)
    • 판매는 1만 원일 때와 같은 하루 12개였고, 비검색 ROAS만 150~235%로 떨어졌습니다.
  • 깻잎순 → 13만 원 → 10만 원(10/29). ROAS가 276%에서 364%로 회복했습니다.
  • 총각김치 → 4만 원 → 2만 원(10/27). ROAS 249~290%가 반복되어 한 단계 줄였습니다.

④ 썸네일·가격 실험

  • 쌈배추 썸네일 (10/26) → ROAS 1,066%(검색 1,255%·비검색 947%)
  • 총각김치 썸네일 (10/28) → 검색 클릭률이 1.5~2.5%에서 3.9~4.7%로 약 2배 올랐습니다. 주말에는 2.5~2.85%로 다소 내려왔지만, 3kg 전환율은 8.73%로 좋습니다.
  • 포기김치 썸네일 (10/30) → 검색 클릭률이 1.70%에서 2.26%(주말 평균)로 올랐습니다.
  • 포기김치 10kg 가격 (10/30) → 59,900원 → 57,900원. 같은 상품 5kg(10.89%)·3kg(8.30%)보다 10kg 전환율(3.23%)만 낮아 가격을 조정했습니다. 주말 하루 1.3개로 목표(하루 1개 이상)를 달성했습니다.

⑤ 파김치 리뉴얼

  • 실행 → 일예산 2만 원 → 1만 원(10/28), 웰빙촌 파김치로 상품 교체(10/30)
  • 결과 → 10/29 하루 1개에서 주말 3일 18개로 늘었고, 전환율은 7.17%입니다. 광고 ROAS는 약 170%로 낮아, 판매는 대부분 자연 유입입니다.

⑥ 신규 상품: 봄동겉절이

  • 실행 → 상품 등록 후 캠페인 신설(10/28, 1만 원, 목표 ROAS 620%), 1만 원 → 2만 원(10/30)
  • 결과 → 첫날 3개 판매, ROAS 1,780%였지만, 2만 원 이후 주말 ROAS는 약 344%로 손익분기(1kg 약 455%) 아래입니다. 11/2 1만 원으로 되돌렸습니다.

4. 지난 보고 과제 점검

  • ① 떡갈비 일반 (20만 원) → ✅ ROAS가 276%에서 365%로 회복했습니다. 15만 원까지 줄이는 테스트로 20만 원 + 신규 25만 원이 최적 조합임을 확인했습니다.
  • ② 동치미 (25만 원·천수무·3kg 추가) → 🔄 리뉴얼 직후 클릭률과 전환율이 떨어졌다가, 가격을 13,900원으로 내린 뒤 전환율 10.25%로 회복했습니다. 이익은 얇습니다.
  • ③ 쌈배추 (2만 원·새 썸네일) → ✅ 썸네일 효과로 ROAS가 크게 올랐습니다. 5만 원 증액은 실패했고, 2만 원이 버티는 선입니다.
  • ④ 겉절이 캠페인 (얼갈이) → 🔄 평일 ROAS는 516%로 회복했고 4일 연속 순이익 플러스입니다. 다만 3kg 방문자가 4일 만에 40% 줄었습니다(3kg 검색 광고비 ▼60%).
  • ⑤ 효율 낮은 캠페인 → 갓김치는 주말 ROAS 약 210%로 11/2 OFF했습니다. 깻잎순은 10만 원으로 줄였고, 전라도 배추김치는 주말 ROAS가 278% → 496% → 642%로 살아나 유지합니다.

5. 다음 주 확인할 것 (11/2 실행분)

  • 떡갈비 일반 (20만 원 → 25만 원) → 하루 판매 140개 이상, 떡갈비 하루 순이익 34만 원 이상 유지 여부. 유지되면 30만 원 → 50만 원 순으로 확대하고, 50만 원부터는 목표 ROAS 400%를 함께 설정합니다. ROAS가 330% 아래면 20만 원으로 복귀합니다.
  • 고들빼기 (10만 원 → 20만 원) → 새 단가표 기준 손익분기가 303%로 낮아져 증액했습니다. ROAS 350% 이상, 하루 판매 50개 이상이면 유지하고, 330% 아래면 15만 원으로 되돌립니다.

네이버는 순위 상품 3개(얼갈이 → 동치미 → 고들빼기)를 한 상품씩 밀고, 나머지는 순수익 상품으로 까는 전략으로 운영했습니다. 주력 3개 중 얼갈이는 성공, 고들빼기는 진입, 동치미는 리뉴얼로 후퇴했습니다. 스토어 매출은 1,125.7만 원에서 1,254.9만 원(▲11.5%)으로 늘었습니다.
이유 →
  • 순위 상품: 얼갈이 성공, 고들빼기 진입, 동치미 후퇴 → 얼갈이 3kg는 카테고리 23위에서 8위로 오르며 매출이 43% 늘었고, 고들빼기는 "고들빼기" 키워드 70위에서 23위로 1페이지에 진입했습니다. 동치미 5kg는 월동무에서 천수무로 리뉴얼한 뒤 "천수무동치미" 등 키워드가 이탈하며 "동치미" 8위에서 30위로 떨어졌지만, 새로 추가한 3kg는 카테고리 1위에 올랐습니다. 순위 상품 전체로는 광고비를 13% 줄이면서 ROAS가 681%에서 836%로 올랐습니다.
  • 순수익 상품: 판매는 늘었지만 효율은 하락 → 광고 구매 매출이 37% 늘었고 총각김치·포기김치 같은 순위 상품 후보도 찾았습니다. 다만 광고비가 81% 늘어 ROAS는 711%에서 539%로 낮아졌습니다.
다음 과제 →
순위 상품을 넓히고, 순수익 상품의 새는 광고비를 막는 것입니다. 얼갈이 3kg는 키워드 1위를 노리고, 총각김치·포기김치를 순위 상품 후보로 올려 테스트합니다. 동치미 5kg는 리뉴얼 후 새 키워드가 자리 잡는지 지켜본 뒤 운영 방향을 정하고, 판매 0건 상품은 계속 정리합니다.

순위는 네이버 순위 조회 기준 · 매출은 스토어 판매금액(순), 광고는 광고 보고서 기준입니다. 세부 내용은 ② 상세 보고 탭에 있습니다.

1. 전략 방향

"순위 상품은 한 상품씩 밀어 순위를 만들고, 나머지는 팔리면 좋은 순수익 상품으로 깐다."

  • 순위 상품 → 손님이 이름으로 검색하는 상품에 광고비를 몰아 순위를 만듭니다. 순위가 잡히면 광고를 줄여도 자연 판매가 남습니다. 순서는 얼갈이(1번 타자, 10/14~) → 동치미(2번 타자, 10/14~) → 고들빼기(3번 타자, 10/26~)입니다.
  • 순수익 상품 → 순위 경쟁 없이 전체 상품에 낮은 입찰가로 그물을 깔아(10/23~), 광고비를 쓰고도 남는 상품만 남기고 판매 0건 상품은 정리합니다.
  • 판단 원칙 → 순위 상품은 "광고로 순위가 오르고, 광고비 증가보다 상품 매출이 더 늘었는가", 순수익 상품은 "광고비를 쓰고도 남는가"로 판단합니다.
  • 결과 → 주력 3개 중 얼갈이는 성공, 고들빼기는 진입, 동치미는 리뉴얼로 후퇴했습니다. 순수익 상품에서는 총각김치·포기김치처럼 순위 상품 후보를 찾았습니다.

지난주(10/19~10/25)와 이번 주(10/26~11/1)를 주간 합계로 비교했습니다. (스토어 판매 데이터·광고 보고서 기준)

스토어

  • 매출 (순) → 1,125.7만 원 → 1,254.9만 원 (▲11.5%)
  • 주문 → 624건 → 664건 (▲6.4%)
  • 방문 → 7,535명 → 9,301명 (▲23.4%)
  • 구매전환율 → 8.28% → 7.14% (▼1.14%p)
  • 객단가 → 18,040원 → 18,899원 (▲4.8%)
  • 환불 → 72.5만 원 → 48.2만 원 (▼34%)

광고

  • 광고비 → 74.6만 원 → 101.5만 원 (▲36%)

  • 매출 대비 광고비 → 6.6% → 8.1%

상품 그룹별 광고 성과

  • 순위 상품 (얼갈이·동치미·고들빼기) → 광고비 35.8만 원 → 31.3만 원(▼13%), 구매 매출 243.9만 원 → 261.7만 원(▲7%), ROAS 681% → 836%
  • 순수익 상품 (나머지) → 광고비 38.8만 원 → 70.2만 원(▲81%), 구매 매출 275.8만 원 → 378.4만 원(▲37%), ROAS 711% → 539%

흐름 → 평일(10/26~29)은 하루 매출 206만~230만 원으로, 지난주 10/22 이후 약세(93.8만~166만 원)에서 회복했습니다. 주말(10/30~11/1)은 하루 107만~149만 원으로 지난 주말과 비슷하게 약했습니다.

광고 구매 매출 기준 안내
광고 보고서의 구매 매출은 광고를 클릭한 손님이 다른 상품을 산 경우도 포함합니다. 그룹별 흐름을 보는 용도이며, 상품별 정확한 매출은 스토어 판매 데이터를 기준으로 봅니다.

3. 순위 상품

① 얼갈이 배추김치: 3kg 성공, 1.5kg 성장 중

3kg (입찰가 500원 → 550원 10/28 → 650원 11/2)

  • 순위 → 카테고리 23위 → 20위(10/26) → 17위(10/27) → 11위(10/28) → 8위, "얼갈이배추김치" 2위 진입, "얼갈이김치" 3위 유지
  • 매출 → 154.3만 원 → 220.8만 원(▲43%), 주문 74건 → 106건, 전환율 13.0% → 14.7%
  • 광고비 → 11.6만 원 → 12.6만 원(▲9%)
  • 의미 → 광고비는 9%만 늘었는데 매출은 43% 늘었습니다. 순위 상승이 자연 판매를 만든다는 것을 확인한 첫 사례입니다. 10/27에는 하루 28건(57.7만 원)으로 최고 기록을 세웠습니다.

1.5kg (입찰가 400원 → 450원 10/27 → 550원 11/2)

  • 순위 → 카테고리 39위 → 32위, "얼갈이김치" 7위 → 9위(10/26) → 4위(10/28) → 6위, "얼갈이배추김치" 4위 진입
  • 매출 → 91.5만 원 → 50.3만 원(▼45%), 주문 68건 → 39건
  • 의미 → 원래 네이버 승부처였지만, 객단가와 전환율이 높은 3kg로 손님이 옮겨갔습니다. 1.5kg는 "얼갈이김치" 키워드 1위를 목표로 계속 밉니다.

② 고들빼기: 진입 (10/26 재오픈)

  • 실행 → 쿠팡·토스에서 검증된 상품을 재오픈했습니다. 입찰가 400원 → 500원(11/2)

  • 매출 → 23.4만 원, 14건, 전환율 6.6%
  • 판단 → 초반에는 광고 판매가 없었지만 자연 판매가 나왔고(10/27), 순위가 빠르게 올랐습니다. 가격은 쿠팡·토스와 같은 14,900원으로 유지했습니다.

③ 동치미: 리뉴얼로 후퇴, 3kg는 1위

5kg

  • 매출 → 77.0만 원 → 60.7만 원, 주문 61건 → 42건

4. 순수익 상품: 그물 2주차

① 순위 상품 후보 발견

  • 총각김치 3kg → 광고 없이도 11일간 40건, 전환율 9~35%였습니다. 10/30 "주력 후보 테스트"로 입찰가를 400원에서 500원으로 올렸고, 주말 광고비 1.9만 원에 구매 ROAS 466%, 11건으로 테스트를 통과했습니다. 매출은 30.5만 원 → 43.2만 원(▲42%)입니다.
  • 포기김치 → 5kg는 주말 구매 ROAS 3,963%, 3kg는 전환율 16.1%로 효율은 높지만 노출이 적었습니다. 3kg 매출은 13.2만 원 → 20.8만 원(▲58%)입니다.

② 판매 0건 상품 정리

  • 10/27 → 판매 0건 상품 12개를 100원으로 내리고, 칼국수를 OFF했습니다.
  • 10/28 → 10월 광고비 상위 그물 상품 14개를 OFF했습니다(10월 광고비 합계 약 8.4만 원).
  • 10/29 → 판매 0건 상품 8개를 100원으로 내렸습니다. 판매 0건 상품 광고비가 하루 6.5만 원에서 5.3만 원으로 줄었습니다.
  • 10/30 → 마이하트 포도 2kg, 시나노골드를 OFF했습니다.

③ 효율 좋은 상품 입찰가 인상 (+50원)

  • 10/27 → 포기김치 10kg 550원, 마이하트 포도 2kg 400원, 생굴무침 350원
  • 10/29 → 포기김치 3kg·갓김치 1kg·쭈꾸미 볶음·소갈비살 350원
  • 10/30 → 닭 내장탕 350원, 쌈배추 1kg 450원
  • 결과 → 포기김치는 효율이 유지됐지만, 포도 2kg(ROAS 106%)·생굴무침(64~151%)은 올리자마자 효율이 무너져 되돌렸습니다. 생굴무침은 방문이 190명에서 540명으로 늘었는데 전환율이 7.9%에서 3.0%로 떨어졌습니다.

④ 남은 과제

  • 판매 0건 상품 광고비 → 주간 9.1만 원에서 14.5만 원으로 늘었습니다. 순수익 상품 ROAS가 711%에서 539%로 낮아진 주된 이유입니다.
